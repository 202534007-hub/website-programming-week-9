
# AI Usage Documentation

## 1. AI Tool
- Tool: ChatGPT

## 2. Tujuan Penggunaan AI
AI digunakan untuk membantu memahami materi HTTP, PHP Foundations, dan Form Handling serta membantu mengembangkan fitur GET dan POST.

## 3. Prompt yang Digunakan
- Membantu membuat fitur pencarian mahasiswa menggunakan GET.
- Membantu membuat formulir pendaftaran mahasiswa menggunakan POST.
- Membantu membuat validasi input pada PHP.
- Menjelaskan penggunaan HTTP 405, 422, dan redirect 303.
- Membantu memeriksa keamanan output menggunakan htmlspecialchars().

## 4. Saran AI yang Digunakan
- Menggunakan GET untuk pencarian mahasiswa.
- Menggunakan POST untuk mengirim data pendaftaran.
- Menggunakan required dan maxlength pada formulir.
- Menggunakan htmlspecialchars() untuk mengamankan output.

## 5. Perubahan yang Dilakukan
- Menggunakan tema Sistem Informasi Mahasiswa.
- Membuat halaman utama.
- Membuat fitur pencarian mahasiswa.
- Membuat formulir pendaftaran.
- Menambahkan validasi menggunakan PHP.

## 6. Hal yang Dipelajari
Saya memahami perbedaan metode GET dan POST, cara membuat formulir HTML, cara mengambil data menggunakan PHP, melakukan validasi input, serta menggunakan status HTTP 405, 422, dan redirect 303.
